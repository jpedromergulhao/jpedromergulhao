## 🧠 About Me

I am a **Software Engineer** specializing in **React, Next.js, Node.js, and TypeScript**. I focus on building scalable web applications, API-driven systems, and production-grade platforms. 

Currently pursuing a **B.Sc. in Computer Science** at the *International University of Applied Sciences*, I blend strong academic foundations with real-world engineering—from architecting full-stack e-commerce platforms to optimizing backend microservices.

- 🏗️ **System Architecture:** Designing resilient REST APIs, microservices, and secure serverless backends focused on data integrity and scalability.
- ⚡ **Frontend Performance:** Crafting pixel-perfect, SEO-optimized, and highly interactive user interfaces using the modern React & Next.js ecosystem.
- 🛠️ **Engineering Standards:** Committed to clean code, strong type safety (TypeScript), modular design, and reliable deployment pipelines.
- 💡 **Product-Minded Approach:** Bridging the gap between technical execution and business value, turning complex requirements into seamless user experiences.
